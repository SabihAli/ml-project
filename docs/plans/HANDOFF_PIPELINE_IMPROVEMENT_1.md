## Latency baseline on this machine (2026-11-14, first profile)

`make profile SEQ=<...>/SNGS-021` (`scripts/pipeline_improvement_1/phase3/profile_latency.py`), RTX 3090,
torch 2.6.0+cu124, TensorRT 10.16.1.11, detector + c5c on TensorRT, calibration backend auto, K=5 inline:

| stage | measured | §1.4 target |
|---|---|---|
| detector | 8.4 ms (p95 10.0) | <= 12 ms OK |
| c5c per call | 9.3-10 ms (armed on 13% of frames, 1.3 ms/frame amortised) | <= 5 ms, 2x over |
| NBJW per run | 36 ms every 5th frame, **inline** | <= 25 ms, off the critical path |
| calibrator on other frames (camera motion) | 7.4 ms p50 | <= 2 ms |
| tracker + roles (CPU) | 4.8 ms | <= 3 ms |
| **e2e** | **p50 23.9, p95 63.7, max 160 ms** (31.3 fps sequential) | p95 <= 25 |

GPU work per frame ~17 ms (detector + amortised NBJW + c5c): ~20 ms GPU headroom. The p95 miss is
scheduling (inline NBJW, CPU optical flow, one thread), not model size. Frame decode (cv2.imread, 8.7 ms)
is excluded (frames preloaded); live needs NVDEC or a decode thread.
